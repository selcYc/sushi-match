## 辨识度高的原因

1. **鱼片的轮廓是对的。** 鱼片是斜刀片出来的：一头宽、一头收成尖，拱在饭团上，两头往下垂，看起来像一道月牙。
   我们之前画的是两头一样圆的椭圆（像药片、像香肠），光看外形就认不出是握寿司。
   **这是最重要的一条，比任何细节都重要。**
2. **不描黑边，靠明暗分形体。** 每个面只用三档颜色：亮面、固有色、暗面。
   黑色描边在小图里会变成一圈脏边，把颜色压暗；不描边，颜色就干净、鲜艳。
3. **每种寿司只抓一两个特征，并且放大。** 三文鱼是白色弧形脂肪纹，虾是红白条纹加尾巴，
   竹荚鱼是银色鱼皮加葱姜，军舰卷是海苔加两片黄瓜。特征之外的地方都简化掉。
4. **高光是几道短短的白色小笔触。** 不是一大片柔光，而是 2～4 道小白线，看起来湿润、新鲜。
5. **米饭大部分被盖住。** 只露出底下一圈，白色加一点冷灰色的阴影，几道短弧线暗示米粒，不画轮廓。
6. **统一的角度和光源。** 一整套插图都用同一个斜放角度、同一个光源方向（左上），放在一起才像一套。

## 落实到我们的插图（tools/draw_sushi.py）

| 原因 | 之前 | 现在 |
|---|---|---|
| 鱼片轮廓 | 对称的椭圆 | 月牙形，左宽右尖，前缘下面加一条两头更厚的侧面 |
| 描边 | 深色描边 | 不描边，亮面 / 固有色 / 暗面三档 |
| 特征 | 平均用力 | 每种只强调 1～2 个特征 |
| 高光 | 一条柔光 + 一条细线 | 一道柔光 + 几道白色小笔触 |
| 米饭 | 一圈描边的花边 | 白色饭团 + 冷灰底 + 短弧线，不描边 |

## 还可以继续改进的

- 白身鱼（鲷鱼、比目鱼、鳍边肉）颜色接近，需要靠「皮的那一边」区分：鲷鱼带一条红皮，鳍边肉有一道道横纹。
- 盘子：店里的盘子边有颜色和花纹，可以考虑用我们的价格颜色，但会泄露答案（价格），暂时保持白盘。
