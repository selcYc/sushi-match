# 插图修改方案（第二轮调研）

> **状态（2026-10-27）**：已按本方案重画全部 48 个词并上线（`tools/draw_sushi.py`）。
> 三项决定都按推荐：视角约 30°、细的同色系描边、相似组。
> 实施中的一个发现：从 30° 看，鱼片背对我们的后半边会被压成一条细线，
> 所以「鱼皮那一侧」的花纹（青背、斑马纹、蟹腿的红色）要画在看得见的前半面。

## 二、关键发现

### 1. 握寿司的标准长相：鱼片「趴」在饭团上，不是「放」在上面

实物照片里几乎每一种都一样：

- 鱼片**比饭团长得多**，中间被饭团顶起来，**两头往下垂、几乎碰到盘子**，侧面看像一个拱。
- 饭团只在中间下方露出一截白色、一粒粒的边。
- 鱼片的厚度因种类而不同：金枪鱼、三文鱼厚实饱满，白身鱼薄而通透。**但没有一种是方块。**

上一轮我把金枪鱼、鲭鱼、鳗鱼画成厚切方块，方向是错的，鳗鱼会像牛排就是这个原因。
真正方方正正的只有**玉子烧**。

### 2. 分辨主要靠「轮廓 + 一条皮边色带 + 配料」，不靠纹理

| 线索 | 例子 |
|---|---|
| **皮的那一侧留下的色带**（白身鱼、光物最关键） | 油甘鱼：鱼片一边有一条**深灰银色的皮**，上面紧贴一道**深红色血合**；鲷鱼：边上一片**粉红色斑驳的皮**；章鱼：边上一圈**紫红色的皮和一排吸盘**，轮廓都被吸盘撑得凹凸不平 |
| **表面花纹**（只在少数几种上是主角） | 鲭鱼：银底上**粗黑的斑马波浪纹**；斑鰶：**顺着鱼身方向**一行行细小的黑点；大腹：粉色上一张**白色脂肪网**；鳍边肉：**一道道横向的棱** |
| **配料**（回转寿司里非常常见，是很强的提示） | 竹荚鱼、沙丁鱼、鲣鱼：顶上一小点**黄色姜泥**（或姜泥加葱）；比目鱼：底下露出一角**绿色紫苏叶** + 红叶萝卜泥；鱿鱼：一小点姜泥；军舰：插两片**黄瓜** |
| **颜色** | 金枪鱼深红、大腹浅粉、长鳍金枪鱼米粉色、三文鱼橙、星鳗浅琥珀、鳗鱼深棕黑 |

いらすとや 的画法几乎就是把上面这些线索挑出来、放大，其余全部省略：
同一个「垂下来的叶片」轮廓，加一条皮边色带或一个配料，就能区分二十多种。

### 3. 照片里的几个「意外」，和我们现在的画法不一致

- **鳍边肉是白色的**，不是奶黄色。辨认靠一道道横棱，表面油亮。
- **鱿鱼是垂下来的一片**，不是长方块。辨认靠「不透明的纯白 + 细刀纹 + 一点姜泥」。
- **鳗鱼**是深棕到黑的烤鱼片，表面**不规则的焦斑**和亮晶晶的酱汁，边缘蓬松、往下垂。没有整齐的烤痕条纹，回转寿司里也大多不加海苔带。
- **星鳗**是浅琥珀色，带细长的纵纹，比鳗鱼浅得多、软得多。
- **斑鰶**的黑点是**顺着鱼身方向排成一行行**，我们现在画成了横排。
- **海螺**是奶白色、厚实有光泽，只在边缘带一点灰褐，我们现在的灰边太重。
- **军舰卷**侧面看海苔围得很高。藏寿司的军舰几乎都插两片黄瓜，滨寿司的不插。

## 三、我们现在的问题

1. **角度太俯视**：从斜上方看，只能看到鱼片的平面轮廓，看不出「拱起来、两头垂下」的立体感，而这正是握寿司最有辨识度的样子。
2. **上一轮的方块方向错了**：金枪鱼系、鲭鱼、鳗鱼。
3. **白色系糊在一起**：白色鱼片放在白盘子上没有边界；比目鱼、鳍边肉、鱿鱼又缺少各自的标志。
4. **皮边色带没画**：油甘鱼、鰤鱼、红甘、鲷鱼最重要的线索（银皮、血合、红皮）现在只有很淡的一块。
5. **几种颜色、花纹和实物不符**：鳍边肉、斑鰶、海螺、鳗鱼（见上一节）。

## 四、修改方案

### A. 整体画法

| 项目 | 现在 | 改成 | 原因 |
|---|---|---|---|
| 视角 | 斜上方约 55°俯视 | **降到约 30°**，更接近侧前方，和店里的照片、いらすとや 一致 | 能看到鱼片拱起、两头垂下的轮廓，以及饭团的高度 |
| 构图 | 盘子上斜摆两贯 | 保留两贯，但**改成左右并排、略微错开**（照片里都是这样摆） | 斜摆在低角度下会互相挡住 |
| 鱼片形状 | 每种一个俯视轮廓 | **统一用「垂下来的叶片」**，再按种类调参数：长度、厚度、两头下垂多少、尖头在哪一边 | 照片里所有生鱼片都是这个基本形，区别在比例 |
| 例外形状 | — | 玉子（厚方块）、扇贝（圆鼓鼓的一块）、赤贝（卷边的蝴蝶形）、虾（带尾巴）、螃蟹（两根蟹腿）、军舰、卷物、豆皮 | 这些在照片里确实不是叶片形 |
| 轮廓线 | 不描边 | **加一条很细、比本色深一档的同色系描边**（不是黑线） | 解决白色鱼片放在白盘子上融成一片的问题；いらすとや 就是这么做的 |
| 辨认线索 | 平均分布在纹理上 | **每种只放大 1～2 个线索**：皮边色带、标志花纹、配料三选一或二 | 照片和插画的共同规律 |

### B. 逐种修改

**赤身**

| 词 | 改法 |
|---|---|
| まぐろ | 叶片形，厚实饱满，深红色，表面光滑带 2～3 道高光，不画纹 |
| ちゅうとろ | 同上，颜色偏粉红，几道淡淡的白色斜纹 |
| おおとろ | 浅粉色，一整张白色脂肪网（大理石纹）是主角 |
| かつお | 深红色，一边是银灰色、带焦痕的炙烤皮边；顶上姜泥加葱 |
| びんちょう | 米粉色，很软很薄、两头垂得最多，表面一层油光 |

**白身**

| 词 | 改法 |
|---|---|
| たい | 半透明白，**一边是粉红色斑驳的皮** |
| ひらめ | 半透明白，**底下露出一角绿色紫苏叶**，上面放红叶萝卜泥和葱 |
| えんがわ | **改回白色**，油亮，**一道道横棱**（棱的阴影用浅灰） |
| はまち | 奶粉色，**一边是深灰银色的皮，皮上方紧贴一道深红血合** |
| ぶり | 和油甘鱼同样结构，但颜色更白、带白色脂肪纹，血合更深更宽 |
| かんぱち | 粉白色，只有一道细细的粉红线，没有深色皮边 |

> 油甘鱼、鰤鱼、红甘三种，实物本来就很难分。建议在游戏里把它们设为「相似组」，同一轮不同时出现（见 C）。

**光物**

| 词 | 改法 |
|---|---|
| あじ | 银色，背侧青灰带深色斑驳；顶上姜泥加葱 |
| さば | **回到叶片形**，银底上粗黑的斑马波浪纹，切口一侧露出粉白的鱼肉 |
| いわし | 细长，亮银色，深蓝色窄背，侧面一排黑点；顶上一点姜泥 |
| こはだ | 银灰，**顺着鱼身方向的一行行细黑点**，表面两三道交叉刀口 |
| さんま | 最长最细，深蓝灰背，一条亮银线；顶上葱 |

**贝类**

| 词 | 改法 |
|---|---|
| ほたて | 圆鼓鼓的一整块，半透明奶桃色，像个小馒头（现在的方向对，加强立体感） |
| あかがい | 橙红色，卷边的蝴蝶形，油亮（现在的方向对） |
| つぶがい | 奶白色厚片，只在边缘带一点灰褐，**去掉现在过重的灰边** |
| ほっきがい | 白色，尖端粉红，中间一道切口（现在的方向对） |
| あわび | 橄榄灰的厚片，深色边缘，交叉刀纹（现在的方向对） |

**虾蟹乌贼章鱼**

| 词 | 改法 |
|---|---|
| えび | 保留：红白条纹 + 扇形虾尾 |
| あまえび | **改成两三只小虾并排**，半透明粉色，各带一个小尾巴 |
| ぼたんえび | 一只大的半透明粉色虾，带红点，大尾巴 |
| かに | 保留两根蟹腿，在低角度下画出圆柱体的立体感 |
| いか | **改回垂下来的叶片形**，不透明的纯白，细刀纹，顶上一小点姜泥；靠细描边和冷灰阴影和白盘子分开 |
| たこ | 白色鱼片，一边是紫红色的皮，**吸盘把轮廓撑得凹凸不平** |

**其他**

| 词 | 改法 |
|---|---|
| たまご | 厚方块，金黄色，侧面能看到层纹；海苔带保留（两种都常见） |
| あなご | 浅琥珀色，又软又宽，细长纵纹，一层薄酱汁的光泽 |
| うなぎ | **重画**：深棕到黑的烤鱼片，叶片形往下垂，表面不规则的焦斑和亮晶晶的酱汁，去掉整齐的烤痕条和方块形 |
| サーモン | 保留，白色脂肪纹稍微调细、调淡 |
| いなり | 保留，加几粒芝麻（滨寿司的做法） |

**军舰、卷物、副菜**：现在的画法和照片基本一致，只跟着新视角调整角度；
军舰卷的海苔在低角度下会显得更高，更像实物。

### C. 游戏里配合的一处改动

在题库里加一个「相似组」标记，抽题时同一组的词不会出现在同一轮：

- 油甘鱼 / 鰤鱼 / 红甘
- 甜虾 / 牡丹虾 / 熟虾
- 竹荚鱼 / 沙丁鱼（都放姜泥）

这些在实物里也很难分辨。放在一起考，考的是「认图的眼力」，而不是「认词」。
图片模式下这样处理更公平；文字模式不受影响。

### D. 实施步骤

1. **先做 6 个样稿**：金枪鱼、油甘鱼、比目鱼、鱿鱼、鳗鱼、星鳗。用新视角加叶片形，覆盖最容易出问题的几类，先确认方向再铺开。
2. 方向确认后，把生成脚本的鱼片部分重写成「叶片形 + 参数」，逐类铺开到 48 个。
3. 加「相似组」。
4. 按游戏里的实际大小（约 70px 高），把白色系、光物、相似组各拼成一张对照图自查，确认分得开再上线。

### E. 需要你决定的

1. **视角要不要降低到约 30°？**（推荐。代价是盘子会变扁，两贯要改成左右并排）
2. **要不要加细的同色系描边？**（推荐。白色寿司放在白盘子上最需要）
3. **要不要加「相似组」？**（推荐）
